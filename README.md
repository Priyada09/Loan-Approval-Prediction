# Loan Approval Prediction

## Project Overview

Loan Approval Prediction is a machine learning minor project developed as part of my learning through Apna College. The project explores how classification algorithms can be used to predict loan approval based on applicant-related features.

## Objectives

- Explore and understand the loan approval dataset.
- Perform data cleaning and handle missing values.
- Analyze patterns using data visualization.
- Encode categorical features and scale numerical features.
- Train and evaluate multiple classification models.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Machine Learning Models

The project evaluates the following classification algorithms:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Gaussian Naive Bayes

The models are evaluated using classification metrics, including accuracy, precision, recall, F1-score, and confusion matrices where implemented in the notebook.

## Project Workflow

1. Data loading and initial inspection
2. Missing-value handling
3. Exploratory data analysis and visualization
4. Categorical encoding
5. Feature selection and preprocessing
6. Train-test split and feature scaling
7. Model training and evaluation
8. Feature engineering and model comparison

## How to Run

1. Clone this repository.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Open the notebook in Jupyter Notebook or VS Code.
4. Ensure the dataset is available at the path specified in the notebook.
5. Run the cells in order.
